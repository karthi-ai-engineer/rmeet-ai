Quickstart
curl example
curl -X POST https://tw-gateway.twave.co.jp/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: YOUR_API_KEY" \
  -d '{
    "model": "default",
    "messages": [
      {
        "role": "user",
        "content": "Hello"
      }
    ]
  }'

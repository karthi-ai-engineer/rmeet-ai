# "Max" — 76-second animated product film (script + storyboard v2)

Karthi (22 Nov 2026): Max is above all a **video-call bot**: open inside the call; the channel comes afterwards.
Tagline: **Max does the work. You give the yes.** Production: free web stack (deterministic timeline rendered frame
by frame with Playwright + ffmpeg), local Kokoro voices, UI sounds generated in code, a licensed music bed.

Audience: executives. 1920×1080, 30 fps, H.264. Works muted (every key line is on screen).
Style (from the x.ai/bot film): recreated vector UI, one idea per shot, push-ins, speech → big kinetic type → real
UI, a cursor click at the decisive moment, spring pops, sound locked to UI events, dark open/close.
Brand: Calm enterprise; the call is dark slate (like Teams); indigo for people's actions; **orange only for Max**.
Small "Demo scenario" tag on product shots (Kestrel Home Goods is fictional).
